# OpenArm 双臂托盘举升任务 — 代码使用文档

本文档说明 **Isaac-Lift-Tray-OpenArm-Bi-v0** 任务的运行环境、安装步骤、训练/评估命令、模块结构与常见问题，便于复现实验并检验代码有效性。

---

## 1. 运行环境

### 1.1 硬件与操作系统

| 项目 | 要求 |
|------|------|
| 操作系统 | Ubuntu 22.04（Linux x86_64） |
| GPU | NVIDIA GPU，支持 CUDA（训练推荐 ≥24 GB 显存用于 4096 envs） |
| 显示 | 本地 GUI 调试需 X11；无头训练加 `--headless` |

### 1.2 软件版本

| 组件 | 版本 |
|------|------|
| Isaac Sim | **5.1.0** |
| Isaac Lab | **2.3.0** |
| Python | **3.11**（扩展包要求 ≥3.10） |
| RSL-RL | **rsl-rl-lib ≥ 3.0.1**（由 `train.py` 运行时检查） |

Isaac Sim / Isaac Lab 由官方安装流程提供，**不在本仓库 `requirements.txt` 中 pin 版本**。本仓库扩展包 `openarm` 额外依赖：**psutil**。

### 1.3 Conda 环境配置（本地安装）

```bash
# 假设已按 Isaac Lab 官方文档创建并安装好 Sim + Lab
conda activate env_isaaclab

# 验证 Python
python --version   # 应显示 3.11.x

# 验证 Isaac Lab 可导入
python -c "import isaaclab; print('isaaclab ok')"
```

### 1.4 Docker 环境（可选）

```bash
docker pull nvcr.io/nvidia/isaac-lab:2.3.0
# 按 README.md 挂载缓存与 DISPLAY 后进入容器
# 容器内工作目录示例：/workspace/openarm_isaac_lab
```

## 4. 运行步骤

### 4.1 训练前检查（推荐）

在 GUI 中确认场景几何与 spawn 时无虚假抓握信号：

```bash
cd ~/openarm_isaac_lab
conda activate env_isaaclab

python scripts/debug/inspect_bimanual_lift.py \
    --num_envs 1 \
    --steps 3000
```

- 会显示左右 TCP 坐标轴（红 X / 绿 Y / 蓝 Z）；
- 终端周期性打印 EE、托盘位置、`capture_band`、`grasp_hold`（初始应接近 0）；
- `Ctrl+C` 退出。

### 4.2 冒烟测试（快速验证训练链路）

```bash
python scripts/reinforcement_learning/rsl_rl/train.py \
    --task Isaac-Lift-Tray-OpenArm-Bi-v0 \
    --num_envs 64 \
    --max_iterations 5 \
    --headless
```

### 4.3 正式训练

```bash
python scripts/reinforcement_learning/rsl_rl/train.py \
    --task Isaac-Lift-Tray-OpenArm-Bi-v0 \
    --headless
```

默认参数（可在 CLI 或 agent cfg 覆盖）：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| num_envs | 4096 | 并行环境数 |
| max_iterations | 8000 | PPO 迭代次数（建议 8000–10000） |
| num_steps_per_env | 64 | 每次 rollout 每环境步数 |
| experiment_name | openarm_bi_tray_lift | 日志子目录名 |

**常用 CLI 覆盖：**

```bash
python scripts/reinforcement_learning/rsl_rl/train.py \
    --task Isaac-Lift-Tray-OpenArm-Bi-v0 \
    --num_envs 2048 \
    --max_iterations 10000 \
    --seed 42 \
    --headless \
    --logger tensorboard
```

**断点续训：**

```bash
python scripts/reinforcement_learning/rsl_rl/train.py \
    --task Isaac-Lift-Tray-OpenArm-Bi-v0 \
    --resume \
    --load_run 2026-06-02_03-23-51 \
    --checkpoint model_500.pt \
    --headless
```

### 4.4 策略评估与回放

```bash
python scripts/reinforcement_learning/rsl_rl/play.py \
    --task Isaac-Lift-Tray-OpenArm-Bi-Play-v0 \
    --num_envs 16 \
    --checkpoint logs/rsl_rl/openarm_bi_tray_lift/<run_name>/model_XXXX.pt
```

Play 配置自动：16 环境、关闭观测噪声、较大 env_spacing。可选 `--video` 录制视频；策略可导出至 run 目录下 `exported/`（TorchScript / ONNX，依 play 脚本实现）。

### 4.5 TensorBoard 分析

```bash
python -m tensorboard.main \
    --logdir=logs/rsl_rl/openarm_bi_tray_lift
```

浏览器打开 `http://localhost:6006/`。

### 4.6 重新生成托盘 USD

修改托盘尺寸后需同步更新 `lift_env_cfg.py` 中几何常量：

```bash
python scripts/tools/build_tray_usd.py
```

### 4.7 抓取就绪姿态探针（可选）

```bash
python scripts/debug/solve_ready_pose.py
```

Headless 搜索使 TCP 到达抓取点的关节配置，用于分析 reach 可行性（非训练必需）。

## 5. 命令行参数说明

### 5.1 `train.py` 主要参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `--task` | str | Gym 任务 ID，本任务为 `Isaac-Lift-Tray-OpenArm-Bi-v0` |
| `--headless` | flag | 无 GUI，服务器训练必加 |
| `--num_envs` | int | 并行环境数量 |
| `--max_iterations` | int | 训练迭代次数 |
| `--seed` | int | 随机种子 |
| `--resume` | flag | 从 checkpoint 继续 |
| `--load_run` | str |  run 文件夹名 |
| `--checkpoint` | str | checkpoint 文件名 |
| `--logger` | str | `tensorboard` 或 `wandb` |
| `--video` | flag | 训练过程录屏（开销大，一般不用） |

完整参数见 `scripts/reinforcement_learning/rsl_rl/cli_args.py`。

### 5.2 `play.py` 主要参数

与 `train.py` 类似，`--task` 应使用 **Play** 变体：`Isaac-Lift-Tray-OpenArm-Bi-Play-v0`。

## 6. 核心配置与函数说明

### 6.1 环境配置类

| 类名 | 文件 | 作用 |
|------|------|------|
| `BimanualTrayLiftEnvCfg` | `lift_env_cfg.py` | MDP 顶层：场景模板、观测/奖励/课程 |
| `OpenArmTrayLiftEnvCfg` | `joint_pos_env_cfg.py` | 填充机器人、托盘、TCP、动作 |
| `OpenArmTrayLiftEnvCfg_PLAY` | 同上 | 评估专用：少 env、无噪声 |
| `OpenArmTrayLiftPPORunnerCfg` | `rsl_rl_ppo_cfg.py` | PPO runner、网络、算法超参 |

### 6.2 关键几何常量

定义于 `lift_env_cfg.py`，修改须同步 `rewards.py`、`observations.py`、`tray.usda`：

| 常量 | 值 | 含义 |
|------|-----|------|
| `HALF_GRASP_Y` | 0.23 m | 抓取点距托盘中心 \|Y\| |
| `TRAY_BASE_HEIGHT` | 0.345 m | 静置质心高度 |
| `MINIMAL_LIFT_HEIGHT` | 0.385 m | 视为离台 |
| `TARGET_HEIGHT` | 0.495 m | 目标举升高度 |

### 6.3 核心奖励函数（`mdp/rewards.py`）

| 函数 | 含义 | 主要参数 |
|------|------|----------|
| `reach_handle` | TCP 到侧面抓取点的 tanh 距离奖励 | `side`, `std`, `half_grasp_y` |
| `grasp_hold` | 靠近 × capture_band 的抓握质量 | `grasp_radius`, finger/ee cfg |
| `grasp_attempt` | 弱监督闭合尝试 | 同上 |
| `tray_lift_height` | 高度 progress（× `_grasp_gate`） | `base_height`, `target_height` |
| `tray_is_lifted` | 离台二元奖励（× 门控） | `minimal_height` |
| `tray_goal_height` | 目标高度 tanh（× 门控） | `target_height`, `std` |
| `tray_flat` | 托盘水平度 | `minimal_height` |
| `ee_height_symmetry` | 左右 EE 高度对称 | `std` |

**内部门控 `_grasp_gate`：** 返回左右 capture quality 的乘积，仅当双手真正夹住时举升奖励才有效。

### 6.4 核心观测函数（`mdp/observations.py`）

| 函数 | 输出 | 说明 |
|------|------|------|
| `ee_position_in_robot_root_frame` | (N,3) | TCP 在机器人 root 系位置 |
| `ee_to_handle_vector_in_robot_root_frame` | (N,3) | TCP 指向抓取点的向量 |
| `tray_position_in_robot_root_frame` | (N,3) | 托盘位置 |
| `tray_orientation_features` | (N,4) | 姿态轴向投影，避免欧拉奇异 |
| `hand_down_alignment` | (N,1) | 手掌向下对齐标量 |
| `hand_span_alignment` | (N,1) | 开合轴与托盘长轴对齐标量 |

### 6.5 终止条件（`mdp/terminations.py`）

| 函数 | 条件 |
|------|------|
| `time_out` | episode 达到 10 s |
| `tray_dropped` | 托盘质心 z < 0.22 m |

### 6.6 四阶段课程（`CurriculumCfg`）

| 阶段 | 触发步数（policy steps） | 效果 |
|------|--------------------------|------|
| 1 | 0 | 仅 reach 有效 |
| 2 | >15000 | grasp_hold=6, grasp_attempt=1.5 |
| 3 | >35000 | 门控 lift 四项开启 |
| 4 | >55000 | tray_flat、对称、平滑惩罚加强 |

换算：约 `步数 / 64 ≈ PPO iteration`（4096 envs 时）。

## 8. 常见问题与解决办法

### Q1：`ModuleNotFoundError: No module named 'openarm'`

**原因：** 未安装扩展包或未激活 conda 环境。  
**解决：**

```bash
conda activate env_isaaclab
cd openarm_isaac_lab
python -m pip install -e source/openarm
```

### Q2：`list_envs.py` 中看不到 Tray Lift 任务

**原因：** `import openarm.tasks` 未执行或安装路径错误。  
**解决：** 确认 `pip install -e source/openarm` 成功；检查 `bimanual/lift/config/__init__.py` 存在。

### Q3：训练 OOM（显存不足）

**原因：** 默认 4096 并行环境占用大。  
**解决：** 降低 `--num_envs`（如 2048、1024）；关闭 `--video`；使用 `--headless`。

### Q4：GUI 无法启动 / 黑屏

**原因：** DISPLAY 或 Vulkan 配置问题。  
**解决：** 本地运行 `xhost +`；Docker 挂载 `.Xauthority`；远程仅做训练时用 `--headless`，inspect 在本地 GUI 机器运行。

### Q5：策略学会“推竖托盘”而非抓取

**原因：** 旧版奖励未门控或课程阶段 3 过早。  
**解决：** 确认使用当前 `rewards.py` 中 `_grasp_gate`；保证阶段 1–2 充分训练（≥550 iter 再观察 lift）；用 inspect 确认 `grasp_hold` 在 spawn 时为 0。

### Q6：reach 奖励不收敛 / TCP 到不了托盘

**原因：** PD 刚度不足或 TCP frame 配置错误。  
**解决：** 确认 `joint_pos_env_cfg.py` 中 stiffness=200；确认 FrameTransformer 跟踪 `openarm_*_ee_tcp`；运行 `inspect_bimanual_lift.py` 对比 TCP 与抓取点距离。

### Q7：checkpoint 找不到

**原因：** 训练未达 `save_interval`（默认每 100 iter）或日志被清理。  
**解决：** 检查 `logs/rsl_rl/openarm_bi_tray_lift/<timestamp>/model_*.pt`；续训用 `--resume`。

### Q8：修改托盘尺寸后奖励异常

**原因：** 几何常量未同步。  
**解决：** 运行 `build_tray_usd.py`，并更新 `HALF_GRASP_Y`、`TRAY_BASE_HEIGHT` 等所有引用处。

### Q9：`rsl-rl-lib` 版本错误

**原因：** Isaac Lab 2.3 需要 rsl-rl ≥ 3.0.1。  
**解决：** 在 `env_isaaclab` 中按 Isaac Lab 官方依赖安装，或 `pip install rsl-rl-lib>=3.0.1`。
