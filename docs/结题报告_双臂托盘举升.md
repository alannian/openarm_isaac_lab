# 基于 Isaac Lab 的双臂 OpenArm 协同托盘举升强化学习项目结题报告

---

## 摘要

随着服务机器人与协作制造的发展，双臂协同操作成为机器人领域的研究热点。传统基于模型的控制方法在复杂接触、多约束协同场景下建模困难、泛化能力有限。本项目基于 NVIDIA Isaac Sim 5.1.0 与 Isaac Lab 2.3.0 仿真框架，在开源 OpenArm 双臂机器人平台上，设计并实现了**双臂协同托盘举升**强化学习（Reinforcement Learning, RL）任务。

研究内容涵盖：自定义扁平板托盘与中央支架场景建模、自然下垂初态下的侧面形封闭抓取、四阶段课程式奖励设计、抓握门控反作弊机制，以及基于 RSL-RL 的 PPO 策略训练与评估流程。研究方法以 Manager-Based RL 环境为核心，采用 16 维关节增量动作空间、约 78 维几何增强观测空间，在 4096 并行环境中进行大规模 on-policy 训练。

核心成果包括：完整可复现的双臂托盘举升 Gym 环境（`Isaac-Lift-Tray-OpenArm-Bi-v0`）、配套调试与 USD 资产构建工具、经过多轮迭代验证的 MDP 与课程学习方案。创新点主要体现在：（1）侧面骑夹板端抓取与形封闭抬升任务设计；（2）“先夹住、再抬起”的四阶段课程与 `_grasp_gate` 门控机制，有效抑制“推托盘竖立骗分”等策略作弊；（3）针对重力下垂问题提升臂部 PD 刚度，并直接使用 USD 内 `ee_tcp` 链路保证奖励—观测几何一致。

**关键词：** 双臂协同操作；强化学习；Isaac Lab；托盘举升；课程学习

## 一、引言

### 1.1 研究背景

双臂机器人可同时操作大尺寸、长条形或需双手稳定持握的物体，在物流搬运、餐饮配餐、实验室自动化等场景具有广泛应用前景。与单臂抓取小方块等典型 benchmark 不同，**双臂协同举升托盘**涉及：长距离到达、双侧同步定位、夹爪形封闭抓取、协同抬升与姿态保持等多重子问题，对仿真环境建模、奖励 shaping 与训练稳定性提出更高要求。

NVIDIA Isaac Lab 基于 Isaac Sim 提供 GPU 加速的并行 RL 训练能力，已成为机器人学习研究的重要基础设施。OpenArm 是开源的 7-DoF 双臂平台，其 Isaac Lab 扩展已支持 reach、cube lift 等任务，但**双臂协同举升定制托盘**仍属本项目自主拓展内容。

### 1.2 研究意义

- **学术意义：** 探索自然初态、长 horizon 到达任务下的课程 RL 设计，以及接触丰富场景中的奖励反作弊方法。
- **工程意义：** 形成可复现的仿真—训练—评估闭环，为后续 sim-to-real 迁移与模仿学习提供基础环境。
- **应用意义：** 托盘/板材类物体的双手协同搬运是仓储与制造中的常见需求，本项目提供了可扩展的仿真验证平台。

### 1.3 国内外研究现状

**机器人运动控制方面，** 传统方法依赖运动学/动力学模型与轨迹优化，在不确定接触下鲁棒性不足。**强化学习方面，** DeepMind、OpenAI 等展示了端到端 RL 在灵巧操作中的潜力；Isaac Gym / Isaac Lab 生态中，Franka、UR 等平台的 lift、cabinet 任务已成为标准 benchmark。**双臂协同方面，** 现有工作多集中于双臂 reach、双手搬运刚性连杆或协作装配，针对**侧面抓取 + 形封闭抬升**的长条物体任务研究相对较少。

**仿真框架方面，** Isaac Lab 2.x 采用 Manager-Based 环境架构，将观测、奖励、终止、事件、课程解耦为可配置模块，便于快速迭代 MDP 设计。RSL-RL 提供高效的 PPO 实现，支持数千环境并行采样。

### 1.4 研究目标

1. 在 Isaac Lab 中搭建双臂 OpenArm + 自定义托盘 + 中央支架的物理仿真场景；
2. 设计合理的动作/观测/奖励/终止与域随机化，使策略能从自然下垂初态学会：到达 → 抓取 → 举升 → 平稳持握；
3. 部署 RSL-RL PPO 训练流程，完成策略训练与可视化评估；
4. 提供完整代码、配置与文档，保证实验可复现。

### 1.5 主要研究内容

| 模块 | 内容 |
|------|------|
| 场景与资产 | 双臂 OpenArm USD、扁平板托盘 USD、中央支架几何 |
| MDP 设计 | 16 维动作、~78 维观测、四阶段奖励、抓握门控、终止条件 |
| 训练框架 | RSL-RL PPO、4096 并行环境、课程学习权重调度 |
| 工具链 | 环境检查脚本、就绪姿态求解、托盘 USD 构建 |
| 实验评估 | TensorBoard 指标、Play 模式策略回放、TorchScript/ONNX 导出 |

## 二、相关理论与技术基础

### 2.1 机器人运动控制原理

本项目采用**关节位置增量控制**：策略网络每步输出 14 维连续动作（左/右各 7 关节）与 2 维二值夹爪动作。臂部通过 PD 执行器跟踪目标关节角（`scale=0.5`，相对默认位姿偏移）；夹爪采用开/合二值指令（张开 0.044 m，闭合 0.0 m）。

末端执行器（TCP）位姿通过 `FrameTransformer` 从 USD 内 `openarm_left/right_ee_tcp` 链路直接读取，避免 hand + 固定 offset 带来的几何不一致。为补偿机械臂在托盘高度（约 0.42 m）处的重力下垂，将臂部执行器刚度由默认 80 提升至 200、阻尼由 4 提升至 24。

### 2.2 强化学习算法

采用 **Proximal Policy Optimization (PPO)** 算法，属于 on-policy  actor-critic 方法，通过 clipped surrogate objective 限制策略更新幅度，训练稳定。关键超参数：折扣因子 γ=0.99，GAE 参数 λ=0.95，clip=0.2，学习率 3×10⁻⁴（adaptive schedule），每环境采样 64 步，8 轮 epoch、8 mini-batch。

Actor/Critic 网络为 3 层 MLP `[256, 256, 128]`，激活函数 ELU，启用经验归一化（empirical normalization）。初始动作噪声 std=0.5，entropy 系数 0.005，以抑制二值夹爪维度的无界漂移。

### 2.3 仿真环境与 Isaac Lab 框架

**Isaac Sim** 提供 GPU 加速的 PhysX 刚体/ articulation 仿真；**Isaac Lab** 在其上封装 `ManagerBasedRLEnv`，通过 ConfigClass 声明：

- **Scene：** 机器人、物体、传感器、灯光、地面；
- **ObservationManager / RewardManager / TerminationManager / EventManager / CurriculumManager：** 模块化 MDP 项；
- **Decimation：** 物理步 100 Hz（dt=0.01），策略步 50 Hz（decimation=2）。

本项目任务注册为 Gymnasium 环境 ID：`Isaac-Lift-Tray-OpenArm-Bi-v0`（训练）、`Isaac-Lift-Tray-OpenArm-Bi-Play-v0`（评估）。

### 2.4 课程学习与奖励 Shaping

针对“到达距离长、接触复杂、易策略作弊”的特点，采用**四阶段课程**：阶段 1 仅 reach；阶段 2 开启 grasp；阶段 3 开启门控 lift；阶段 4 强化平稳与对称。权重通过 `modify_reward_weight` 在固定环境步数（15000 / 35000 / 55000 policy steps）切换。

**抓握门控 `_grasp_gate`：** 举升类奖励乘以左右手 capture quality（靠近抓取点 × 夹爪闭合 band），确保只有真实夹持才能获得举升梯度，阻断“推倒托盘使质心升高”的作弊路径。

## 三、项目实现过程

### 3.1 仿真环境搭建

#### 3.1.1 机器人与场景

- 机器人：`openarm_bimanual.usd`，双臂各 7 DoF + 平行夹爪；
- 初始姿态：全部臂关节 0（自然下垂），夹爪张开；
- 地面 + 穹顶光标准配置。

#### 3.1.2 托盘与支架

托盘为 **0.36 × 0.50 × 0.03 m** 扁平板（长轴 +Y），质量 0.5 kg，由 `scripts/tools/build_tray_usd.py` 生成 `tray.usda`，网格顶点烘焙以避免 Isaac 导入 scale 异常。

中央支架为 **0.12 × 0.24 × 0.33 m** 立方体，托住托盘中部，使两端（±0.23 m）悬空，便于夹爪从侧面套住板端形成形封闭。托盘静置质心高度 0.345 m，目标举升高度 0.495 m（约 +15 cm）。

#### 3.1.3 几何常量一致性

`lift_env_cfg.py`、`rewards.py`、`observations.py`、`joint_pos_env_cfg.py` 与 `tray.usda` 共享 `HALF_GRASP_Y=0.23`、`TRAY_BASE_HEIGHT=0.345` 等常量，保证奖励目标点、观测向量与可视化一致。

### 3.2 强化学习框架部署

1. 安装 Isaac Lab 2.3.0 与 Isaac Sim 5.1.0（conda 环境 `env_isaaclab` 或 Docker）；
2. 克隆 `openarm_isaac_lab` 并执行 `python -m pip install -e source/openarm`；
3. 验证环境列表：`python scripts/tools/list_envs.py`，确认出现 `Isaac-Lift-Tray-OpenArm-Bi-v0`；
4. 启动训练：`python scripts/reinforcement_learning/rsl_rl/train.py --task Isaac-Lift-Tray-OpenArm-Bi-v0 --headless`；
5. 日志目录：`logs/rsl_rl/openarm_bi_tray_lift/`；TensorBoard 可视化训练曲线。

### 3.3 核心算法设计与优化

#### 3.3.1 动作空间（16 维）

| 分量 | 维度 | 说明 |
|------|------|------|
| left_arm_action | 7 | 关节位置增量，scale=0.5 |
| right_arm_action | 7 | 同上 |
| left/right_gripper | 各 1 | 二值开/合 |

#### 3.3.2 观测空间（约 78 维）

| 类别 | 项 | 维度 |
|------|-----|------|
| 本体感知 | 左右关节 pos/vel、手指 pos | 32 |
| 抓取几何 | 左右 EE 位置、ee_to_handle 向量 | 12 |
| 托盘状态 | 位置、姿态特征、线/角速度 | 10 |
| 手部提示 | hand_down / hand_span 对齐标量 | 4 |
| 历史 | 左右臂 last_action | 14 |
| 噪声 | 训练时 enable_corruption | — |

#### 3.3.3 奖励函数迭代历程

| 版本 | 问题 | 改进 |
|------|------|------|
| v1 | 举升奖励硬门控，随机策略采不到正样本 | 分阶段开启，先 reach+grasp |
| v2 | 举升无门控，策略推竖托盘骗分 | 引入 `_grasp_gate` 乘子 |
| 当前 | 自然下垂初态 reach 困难 | 四阶段课程 + 提高 PD 刚度 |

主要奖励项：`reach_handle`（tanh 距离）、`grasp_hold` / `grasp_attempt`、`tray_lift_height` / `tray_is_lifted` / `tray_goal_height`（门控）、`tray_flat`、`ee_height_symmetry`、平滑惩罚。

#### 3.3.4 终止与域随机化

- **超时：** episode 10 s（500 policy steps）；
- **托盘掉落：** 质心 z < 0.22 m；
- **Reset 随机化：** 托盘 xy ±3 cm、yaw ±0.05 rad；关节 ±0.05 rad。

### 3.4 代码编写思路

项目遵循 Isaac Lab 官方任务结构：

```
bimanual/lift/
├── lift_env_cfg.py          # 场景、观测、奖励、课程顶层配置
├── config/
│   ├── joint_pos_env_cfg.py # 机器人/托盘/TCP/动作实例化
│   ├── __init__.py          # Gym 注册
│   └── agents/              # RSL-RL / rl_games / skrl 配置
└── mdp/
    ├── observations.py      # 自定义观测项
    ├── rewards.py           # 自定义奖励与门控
    └── terminations.py      # 托盘掉落判定
```

**设计原则：** 配置与逻辑分离；几何常量单点定义；奖励函数内联文档说明设计动机；调试脚本独立于训练主路径。

### 3.5 实验方案设计

| 项目 | 设置 |
|------|------|
| 算法 | PPO (RSL-RL) |
| 并行环境 | 4096（训练）/ 16（Play） |
| 每环境步数 | 64 |
| 最大迭代 | 8000–10000（覆盖四阶段课程，≈859 iter 进入阶段 4） |
| 随机种子 | 默认 + 可选 `--seed` |
| 评估 | Play 模式加载 checkpoint，关闭观测噪声 |
| 消融/调试 | inspect 零动作可视化；solve_ready_pose IK 探针 |

**建议记录的指标：** episode return、各奖励分项均值、`grasp_hold` / `lift_height` 激活率、托盘高度、episode 长度、策略 KL。

## 四、实验结果与分析

### 4.1 训练环境验证

- `list_envs.py` 成功注册双臂托盘举升任务；
- `inspect_bimanual_lift.py` 在 GUI 中验证：TCP 坐标轴、托盘/支架相对位置、spawn 时 `capture_band ≈ 0`（无虚假抓握奖励）；
- 冒烟训练（`--num_envs 64 --max_iterations 5`）可正常启动仿真与 PPO 更新循环。

### 4.2 训练过程分析（定性）

根据 MDP 设计与多轮迭代经验，训练过程可预期呈现以下阶段特征：

1. **阶段 1（0–~234 iter）：** return 主要由 `reach_coarse/fine` 贡献，双臂从下垂姿态逐渐伸向托盘两端；
2. **阶段 2（~234 iter 起）：** `grasp_hold` 权重升至 6.0，策略开始学习闭合夹爪并维持 capture；
3. **阶段 3（~547 iter 起）：** 门控举升奖励激活，托盘质心高度曲线应上升，需观察是否出现“推竖”退化（门控应抑制）；
4. **阶段 4（~859 iter 起）：** `tray_flat`、对称与平滑惩罚加强，举升后姿态应趋于水平、角速度降低。

> **说明：** 完整定量曲线与策略视频请从 `logs/rsl_rl/openarm_bi_tray_lift/` 导出 TensorBoard 截图及 `play.py --video` 录制片段，插入本节与附录。本地若仅保留 Hydra params 而无 checkpoint，需重新训练至阶段 3 以后以获取可展示结果。

### 4.3 关键参数对比实验（配置演化）

| 参数 | 早期运行 | 当前推荐 |
|------|----------|----------|
| num_steps_per_env | 48 | 64 |
| max_iterations | 3000 | 8000–10000 |
| 网络结构 | [256,128,64] | [256,256,128] |
| init_noise_std | 1.0 | 0.5 |
| desired_kl | 默认 | 0.016 |
| 课程阶段 | 2 阶段 | 4 阶段 |
| 初态 | 预弯就绪姿态 | 自然下垂 |

 deeper 网络与更长训练有助于长 horizon 到达；降低初始噪声减轻夹爪漂移；四阶段课程缓解 v1/v2 的收敛与作弊问题。

## 五、创新点总结

本项目在 OpenArm Isaac Lab 开源框架基础上，主要创新拓展如下：

1. **任务与场景创新：** 首次实现双臂 OpenArm **侧面骑夹扁平板托盘**任务，含中央支架 + 悬空板端形封闭抓取几何，区别于单臂 cube lift 与双臂 reach。
2. **MDP 与反作弊创新：** 提出 `_grasp_gate` + `capture_band` 抓握质量度量，与四阶段课程配合，系统解决“不抓悬停”与“推竖骗分”两类典型失败模式。
3. **初态与控制创新：** 采用完全自然下垂初态，更贴近真实上电状态；针对重力下垂提高 PD 刚度，保证 reach/grasp 几何可学。
4. **工程一致性创新：** TCP 直接绑定 USD `ee_tcp` link；托盘 USD 程序化构建；inspect / solve_ready_pose 调试链路与奖励定义对齐。
5. **训练配置优化：** 针对 16 维动作与 ~78 维观测调整网络深度、噪声与 KL 目标，适配长 episode 与二值夹爪动作特点。

## 六、问题与展望

### 6.1 现存不足

1. **Sim-to-real  gap：** 当前仅在仿真中验证，未部署至真实 OpenArm 硬件；
2. **训练成本：** 4096 环境对 GPU 显存要求高，完整 10000 iter 训练耗时较长；
3. **成功判据：** 尚未系统化批量评估成功率与泛化（托盘位姿随机范围可进一步扩大）；
4. **文档同步：** 部分早期 design doc 与当前代码参数存在偏差，需以源码为准统一。

### 6.2 未来研究方向

1. **域随机化增强：** 摩擦、质量、支架高度、传感器噪声；
2. **模仿学习预训练：** 用 `solve_ready_pose` 或遥操作轨迹作 BC 初始化，缩短 reach 阶段；
3. **Sim-to-real：** 导出 ONNX/TorchScript，对接真实关节控制器；
4. **任务扩展：** 托盘搬运至目标区域、堆叠、动态障碍物；
5. **算法对比：** rl_games、SKRL、SAC 等与 PPO 的效果对比。
